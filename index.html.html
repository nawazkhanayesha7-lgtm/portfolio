Behind My Website

How I Built My Portfolio

My portfolio is made from different web technologies. Each one has its own job: one builds the page structure, another designs its look, and another makes the features interactive.

</>

HTML — Structure

HTML creates the content and sections of the website, including the navigation bar, Home, About, Courses, Projects, Certificates and Contact areas, as well as headings, text, cards, forms and buttons.

🎨

CSS — Design & Layout

CSS controls the purple-and-black theme, colors, fonts, spacing, borders, glowing effects, cards, animations and responsive layouts so the portfolio can adjust to different screen sizes.

⚡

JavaScript — Functionality

JavaScript powers interactive features such as the typing text, project filters, mini-project demos, quizzes, video controls, admin actions, certificate handling, backup and restore, and the Back to Top button.

How they work together: HTML provides the structure, CSS makes it attractive and responsive, and JavaScript adds interaction. The uploaded mini-task videos are stored in the browser's IndexedDB, with a backup option available in the portfolio.
